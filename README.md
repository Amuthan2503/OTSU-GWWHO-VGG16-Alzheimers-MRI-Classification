# OTSU-GWWHO-VGG16-Alzheimers-MRI-Classification
This repository implements a complete deep learning pipeline for Alzheimer’s Disease detection and classification from MRI brain scans. The system combines data augmentation, Otsu thresholding optimized with Gaussian Weight Wild Horse Optimization (OTSU-GWWHO) for ROI segmentation, and VGG16 transfer learning-based classification.
